# dc-drive-cpp

DCDrive (Modelica) as a Paperboat backend, generated by
`paperboat modelica generate modelica/DCDrive.mo --out .` (path: ode).

- Station: one `dc-drive` object; its props are the model's parameters and fixed starts.
- Flow: its linked block takes v and gives w, phi, i.

Regenerate after editing the `.mo`; `descriptor.toml`, `backend.toml` and this file are
written once and kept.
